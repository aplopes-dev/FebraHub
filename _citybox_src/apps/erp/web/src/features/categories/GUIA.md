# Guia — Categorias

## O que é

Categorias são os grupos que você usa para organizar os seus produtos. Em vez de
deixar tudo misturado, você separa os itens em grupos com nome — por exemplo:
Vestuário, Calçados, Casa ou Acessórios.

## Para que serve

Organizar bem as categorias ajuda no dia a dia do negócio:

- **Encontrar produtos mais rápido**, filtrando por grupo em vez de procurar um
  a um.
- **Deixar a vitrine e o cardápio organizados**, com os itens agrupados de um
  jeito que o cliente entende.
- **Ter relatórios mais claros**, sabendo quanto cada grupo de produtos vende.
- **Padronizar o cadastro**, porque todo produto novo já entra em um grupo
  conhecido.

## Como usar

### A tela de lista

Ao abrir Categorias, você vê todos os grupos já cadastrados. Cada linha mostra:

- O **nome** da categoria.
- A quantidade de **produtos** que já estão naquela categoria.
- O **status**, que indica se a categoria está ativa ou inativa.

No topo da tela você pode **buscar** por nome e usar o botão **Nova categoria**
para cadastrar um grupo do zero.

### Criar ou editar uma categoria

Ao criar uma nova categoria ou clicar em **Editar**, abre-se um painel na
lateral com os campos:

- **Nome:** como o grupo será chamado. É o único campo obrigatório.
- **Ativa:** quando desligada, a categoria deixa de aparecer no cadastro de
  produtos, mas continua guardada.

Ao terminar, clique em **Salvar** para gravar, ou em **Cancelar** para sair sem
alterar nada.

### Excluir uma categoria

No menu de cada linha há a opção **Excluir**. O sistema pede uma confirmação
antes de remover, porque essa ação não pode ser desfeita. **Não é possível
excluir** uma categoria que ainda tenha produtos vinculados — primeiro mova ou
exclua os produtos daquele grupo.

## Em resumo

As categorias são a forma de arrumar o seu catálogo em grupos que fazem sentido
para o negócio. Mantê-las organizadas facilita encontrar produtos, deixa a
vitrine mais clara para o cliente e torna os relatórios mais úteis.
