# Guia — Categoria de clientes

## O que é

Categorias de cliente são grupos que você usa para segmentar a sua base de
clientes — por exemplo: Varejo, Atacado, VIP, Funcionário ou Revenda. Cada
categoria tem um nome e uma porcentagem de desconto associada.

## Para que serve

- **Aplicar desconto automático** por perfil de cliente, sem precisar
  negociar preço a cada venda.
- **Segmentar relatórios e campanhas** por tipo de cliente.
- **Padronizar a política comercial**, já que todo cliente novo entra em um
  grupo com regras já definidas.

## Como usar

### A tela de lista

Ao abrir Categoria, você vê todas as categorias já cadastradas. Cada linha
mostra o **nome** da categoria, a **porcentagem de desconto** aplicada aos
clientes daquele grupo e a **quantidade de clientes** que já estão
cadastrados naquela categoria.

No topo da tela você pode **buscar** por nome e usar o botão **Nova
categoria** para cadastrar um grupo do zero.

### Criar ou editar uma categoria

Ao clicar em **Nova categoria** ou em **Editar**, abre-se um modal com os
campos:

- **Nome:** como o grupo será chamado. Campo obrigatório.
- **Porcentagem de desconto:** o desconto aplicado às vendas para clientes
  dessa categoria (0 a 100%).

Ao terminar, clique em **Salvar** para gravar, ou em **Cancelar** para sair
sem alterar nada.

### Excluir uma categoria

No menu de cada linha há a opção **Excluir**. O sistema pede uma confirmação
antes de remover, porque essa ação não pode ser desfeita.

## Em resumo

Categorias de cliente organizam a base de clientes por perfil de desconto,
tornando a política comercial mais clara e consistente.
