# Facilita NFE — guia de uso

## O que é

A tela **Facilita NFE** (menu **Finanças → Facilita NF-e**) reúne, num só lugar, os
documentos fiscais da sua loja: notas emitidas por você e — no futuro — notas que
fornecedores emitiram contra a sua loja, além do histórico de reenvios por e-mail.

Hoje ela tem 3 abas:

- **Emitido** — funciona de verdade. Mostra todas as notas fiscais (NF-e, NFS-e e
  cupom NFC-e) que a sua loja já emitiu.
- **Recebido** — ainda **em breve**. Vai mostrar as notas que fornecedores emitiram
  contra a sua loja.
- **Histórico de Envios** — ainda **em breve**. Vai mostrar o histórico de reenvios de
  notas por e-mail.

## Como usar a aba "Emitido"

1. Abra **Finanças → Facilita NF-e**. A tela já abre na aba "Emitido".
2. No topo você vê 5 quadrinhos de resumo: **Total**, **Autorizadas**, **Canceladas**,
   **Manifestações finais** e **Não manifestadas**.
   - Os 3 primeiros mostram números reais da sua loja.
   - Os 2 últimos ("Manifestações finais" e "Não manifestadas") sempre aparecem
     zerados — eles só fazem sentido para notas **recebidas** de fornecedores, algo
     que ainda não existe nesta tela.
3. Use a caixa **"Buscar por"** para procurar um documento (por número, série ou nome
   do cliente).
4. Use o botão **Filtro** para restringir por status ou por modelo de documento
   (NF-e/NFS-e/NFC-e).
5. A tabela mostra Data de emissão, Status, Cliente, Valor, Número, Série e Modelo de
   cada documento. Se a loja tiver muitos documentos, use a paginação no rodapé da
   tabela.
6. A coluna **Ações** tem dois botões — **XML** e **PDF** — para baixar o arquivo
   daquele documento. Eles só ficam ativos quando o documento foi **autorizado**
   pelo órgão fiscal (NF-e/NFC-e) ou **autorizado** no caso de NFS-e; para um
   documento rejeitado ou ainda pendente, os botões ficam desabilitados — passe o
   mouse para ver o motivo.

## O que fazer se aparecer "Emitente fiscal não configurado"

Isso significa que a sua loja ainda não tem um Emitente fiscal cadastrado para emitir
documentos. Fale com o time de suporte para configurar o Emitente fiscal antes de usar
esta tela.

## O que ainda não dá para fazer aqui

- Ver notas recebidas de fornecedores (aba "Recebido")
- Reenviar uma nota por e-mail ou agendar um envio
- Consultar o histórico de envios

Essas funções dependem de um trabalho ainda não feito nos sistemas por trás da tela —
elas aparecem no menu, mas ainda não têm dado nenhum atrás.
