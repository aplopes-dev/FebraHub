# Guia — Grupo financeiro

## O que é

Grupo financeiro é a forma de organizar as contas do seu negócio em categorias
maiores — por exemplo, **Receitas**, **Despesas** ou **Custos**. Cada plano de
contas fica ligado a um grupo, o que deixa relatórios e lançamentos mais claros.

## Para que serve

Com os grupos financeiros cadastrados, você consegue:

- Separar o que é **receita** (dinheiro que entra) do que é **despesa** (dinheiro
  que sai).
- Agrupar várias contas do plano de contas sob o mesmo guarda-chuva.
- Filtrar e analisar os resultados financeiros com mais facilidade.

## Como usar

### Abas

- **Ativos** — grupos em uso.
- **Excluídos** — grupos removidos que podem ser restaurados.

### A tela de lista

Ao abrir Grupo financeiro, você vê os grupos da aba atual. Nela você pode:

- **Buscar** pelo nome do grupo.
- **Filtrar por Tipo** — Todos, Receita ou Despesa.
- Ver, de cada grupo, o **nome** e o **tipo**.
- Usar o botão **Novo grupo** para cadastrar um grupo novo (nome + tipo).

### Ações de cada grupo

No botão de ações (os três pontos) de cada linha você encontra:

- **Editar** — ajusta nome e tipo do grupo.
- **Excluir** — move o grupo para a aba Excluídos. Se o grupo ainda tiver contas
  do plano de contas vinculadas, a exclusão é bloqueada.
- **Restaurar** (na aba Excluídos) — devolve o grupo aos Ativos. Se outro grupo
  ativo já usar o mesmo nome, a restauração falha.

## Dicas

- Prefira nomes curtos e estáveis (ex.: "Receitas", "Despesas fixas").
- O tipo (receita/despesa) influencia relatórios como o DRE.
