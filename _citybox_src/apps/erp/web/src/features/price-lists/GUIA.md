# Guia — Lista de Preços

## O que é

A Lista de Preços é uma tabela de valores que você aplica aos seus produtos em
um determinado contexto de venda. Em vez de ter um único preço para cada
produto, você pode manter várias tabelas — por exemplo, uma para o **Atacado**,
uma de **Promoção**, uma para clientes **VIP** e a tabela **Padrão** do dia a
dia.

## Para que serve

Ter mais de uma lista permite cobrar preços diferentes conforme o momento, o
canal de venda ou o tipo de cliente, sem precisar recadastrar o produto toda vez:

- **Vender no atacado com desconto** para quem compra em grande quantidade.
- **Fazer promoções por tempo determinado**, com data de início e fim.
- **Oferecer condições especiais** a clientes fiéis ou a um canal específico
  (loja física, entrega, marketplace).
- **Manter tudo organizado**: cada lista guarda seus próprios preços e você
  escolhe qual usar em cada situação.

## Como usar

### 1. Crie uma lista

Na tela de Lista de Preços, clique em **Nova lista de preços**. Preencha:

- **Nome:** como você reconhece a tabela (ex.: "Atacado", "Promoção de Verão").
- **Regra de ajuste:** como os preços dessa lista são calculados a partir do
  preço base de cada produto. Você pode escolher:
  - **Preços manuais:** você digita cada preço à mão, sem cálculo automático.
  - **Acréscimo %:** soma uma porcentagem ao preço base (preço maior).
  - **Desconto %:** tira uma porcentagem do preço base (preço menor).
  - **Valor fixo sobre a base:** soma um valor em reais ao preço base.
- **Canais:** em quais canais de venda essa lista vale (loja física, entrega,
  marketplace, cardápio digital). Se você não escolher nenhum, vale para todos.
- **Vigência:** o período em que a lista fica válida. É opcional — sem prazo, a
  lista vale por tempo indeterminado.
- **Ativa:** ligue ou desligue a lista. Listas desligadas deixam de ser
  aplicadas nas vendas.

Clique em **Salvar**.

### 2. Escolha quais produtos entram na lista

Ao abrir uma lista (clicando sobre ela ou em **Gerenciar preços** no menu de
ações), o topo da tela mostra um resumo com as informações da lista — regra de
ajuste, vigência, quantidade de produtos, status e canais de venda. Abaixo, a
lista começa **sem mostrar todos os produtos** — você decide quais fazem
parte dela. Clique em **Gerenciar produtos** para abrir a seleção, marque um ou
vários produtos de uma vez e confirme. Só os produtos escolhidos passam a
aparecer na lista. Para tirar um produto, use o ícone de lixeira na linha dele.

### 3. Ajuste os preços

Para cada produto incluído você vê:

- O **preço base** (o preço de referência do produto).
- O **preço na lista**, já preenchido de acordo com a regra que você escolheu —
  e que você pode **alterar manualmente** quando quiser um valor específico.

**Edição em lote:** marque a caixa de seleção de vários produtos e use **Editar
valor** para ajustar todos de uma vez — aumentar ou reduzir por porcentagem,
aumentar ou reduzir por um valor fixo, ou igualar todos ao mesmo preço.

### 4. Salve as alterações

Ao mexer nos preços, aparece um aviso de que há alterações não salvas. Clique em
**Salvar** para confirmar, ou em **Descartar alterações** para voltar tudo como
estava.

### Definir a prioridade das listas

Na tela principal, as listas aparecem em ordem alfabética, e a coluna
**Prioridade** mostra qual é a preferida: a lista de maior prioridade aparece
marcada como **Prioritária**, e as demais como 2ª, 3ª, e assim por diante.

Para mudar essa ordem, clique no botão **Priorizar**. Abre uma janela lateral
onde você arrasta as listas para cima ou para baixo — a que ficar no topo passa a
ter a maior prioridade quando houver conflito durante a venda. Clique em **Salvar
prioridade** para confirmar.

### Editar ou excluir uma lista

No menu de ações de cada linha (o botão com três pontos), você pode **Editar** os
dados da lista (nome, regra, canais, vigência) ou **Excluir** a lista quando não
precisar mais dela.

## Em resumo

A Lista de Preços dá a você o controle de vender o mesmo produto por valores
diferentes conforme a ocasião — atacado, promoção, cliente especial — de forma
organizada e sem retrabalho, definindo uma regra de cálculo e ajustando os
preços quando fizer sentido.
