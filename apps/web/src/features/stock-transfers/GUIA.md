# Guia — Transferências de estoque

## O que é

Transferências é o recurso para remanejar produtos de um estoque para outro —
por exemplo, do depósito central para a loja, ou da loja para o estoque de
delivery.

## Para que serve

Com as transferências você:

- Move quantidade de produtos entre estoques do mesmo negócio.
- Registra de onde o produto sai e para onde ele vai.
- Informa a data, o responsável e, se quiser, a transportadora e uma observação.
- Acompanha o histórico das transferências ativas e das que foram canceladas.

Diferente das **movimentações** (entrada ou saída avulsa por quebra, ajuste
etc.), a transferência não muda o total geral do negócio: só muda **onde** o
produto está.

## Como usar

### A tela de lista

Ao abrir **Transferências**, você vê o histórico. Nela você pode:

- Separar por abas: **Ativas** e **Canceladas**.
- **Buscar** por ID, estoque ou nome do responsável.
- Usar **Filtro** para restringir por estoque de saída e/ou entrada.
- Clicar em **Nova transferência** para registrar um remanejamento.
- No menu da linha, **Cancelar** uma transferência ativa (ela vai para a aba
  Canceladas).

### Registrar uma nova transferência

1. No bloco **Produtos**, clique em **Adicionar** e selecione os itens. Informe
   a **quantidade** e, se precisar, o **lote**.
2. Em **Informações básicas**, escolha o **estoque de saída**, o **estoque de
   entrada** e a **data da operação**. Os dois estoques precisam ser
   diferentes.
3. Em **Dados para transferência**, preencha o **nome do responsável**. A
   transportadora e a observação são opcionais.
4. Clique em **Salvar**. Se ainda estiver editando, o sistema avisa que há
   alterações não salvas; use **Descartar alterações** para voltar como
   estava.

## Em resumo

Use Transferências para mover produtos entre estoques. Use Movimentações quando
a quantidade entra ou sai do negócio (quebra, ajuste, entrada avulsa).
