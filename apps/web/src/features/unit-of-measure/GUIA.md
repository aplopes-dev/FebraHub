# Guia — Unidade de medida

## O que é

Unidade de medida é a forma como cada produto do seu negócio é contado, pesado
ou medido. É o que diz se um item é vendido por unidade, por quilo, por litro,
por metro, e assim por diante. Exemplos comuns: unidade (un), quilograma (kg),
litro (L), metro (m), caixa (cx) e dúzia (dz).

## Para que serve

Cadastrar as unidades de medida deixa o restante do sistema mais organizado e
correto:

- Ao cadastrar um produto, você escolhe em qual unidade ele é vendido — por
  exemplo, um queijo vendido por quilo ou um refrigerante vendido por unidade.
- Define quantas casas decimais aquela unidade aceita. Isso importa porque um
  item vendido por peso pode precisar de valores como 1,250 kg, enquanto um item
  vendido por unidade só faz sentido em números inteiros (1, 2, 3).
- Mantém padrão em todo o negócio: as mesmas siglas aparecem nas vendas, no
  estoque e nos relatórios.

## Como usar

### A tela de lista

Ao abrir Unidade de medida, você vê a lista de todas as unidades já cadastradas.
Nela você pode:

- **Buscar** por nome ou sigla.
- Ver, de cada unidade, o **nome**, a **sigla**, o **tipo** (se é de contagem,
  peso, volume, comprimento ou área), as **casas decimais** aceitas e o
  **status** (ativa ou inativa).
- Usar o botão **Nova unidade** para cadastrar uma unidade do zero.

### Criar uma unidade

1. Clique em **Nova unidade**. Um painel abre no lado direito da tela.
2. Preencha o **Nome** (por exemplo, "Quilograma") e a **Sigla** (por exemplo,
   "kg").
3. Escolha o **Tipo** que melhor descreve a unidade: Unidade, Peso, Volume,
   Comprimento ou Área.
4. Informe as **Casas decimais** aceitas, de 0 a 3. Use 0 para itens contados
   inteiros e um número maior para itens medidos com fração.
5. Deixe a chave **Ativo** ligada para que a unidade fique disponível na hora de
   cadastrar produtos.
6. Clique em **Salvar**.

### Editar uma unidade

Na lista, clique no botão de ações (os três pontos) da unidade desejada e
escolha **Editar**. O mesmo painel abre com as informações preenchidas. Faça os
ajustes e clique em **Salvar**.

### Excluir uma unidade

No mesmo botão de ações, escolha **Excluir**. O sistema pede uma confirmação
antes de remover, para evitar exclusões por engano. Essa ação não pode ser
desfeita.

### Ativar ou desativar

Se você não usa mais uma unidade, mas não quer removê-la, basta editá-la e
desligar a chave **Ativo**. Assim ela deixa de aparecer no cadastro de produtos,
mas continua registrada.

## Em resumo

As unidades de medida são a base para vender cada produto do jeito certo — por
peso, volume, comprimento ou simples contagem. Mantê-las bem cadastradas garante
preços, estoque e relatórios coerentes em todo o sistema.
